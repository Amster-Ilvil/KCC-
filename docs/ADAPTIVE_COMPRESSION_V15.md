# v1.5 智能压缩与漫画图像处理

本轮在 v1.4“压缩生成文件”的像素无损基础上继续增强，目标不是盲目提高压缩强度，而是：

1. 对每张图先识别真实格式和风险；
2. 在多个安全候选中选择真正更小的一个；
3. 所有默认无损候选都进行解码像素复核；
4. 扫描件裁边/纠斜/漂白与无损压缩严格分离，默认关闭；
5. 不增加 OpenCV / NumPy 等主 GUI 新依赖。

## 参考来源

### Novel-formatter

借鉴 `adapters/scan_preprocess.py` 的工程原则：

- 非破坏式处理，源文件不改；
- 几何判断置信度不足时回退原图；
- 用 Pillow 完成轻量扫描预处理；
- 投影评分判断轻微歪斜；
- 大尺度背景估计 + 亮度平坦化；
- 在彩色区域恢复/保护原图，避免插图被漂白。

借鉴 `builder/epub_builder.py`：

- 不相信扩展名，优先检查 PNG/JPEG/GIF/SVG 的真实 magic bytes；
- 图片优化后只有文件更小时才替换；
- EPUB 输出必须保持正确 MIME / ZIP 结构。

### Colortina

借鉴 `core/image_filter.py` 的保护思路：

- 纸白不能被统一调灰；
- 实心黑线稿不能因为对比度调整而漂移；
- 强边缘需要额外保护；
- 高饱和彩色区域不能套统一“漂白层”。

v1.5 的扫描增强因此会生成纸白、黑墨、边缘和彩色保护 Mask，并将这些区域从原图合成回来。

### ImageOptim / OxiPNG / MozJPEG

借鉴 ImageOptim “按格式组合多个专用优化器”的设计，而不是试图用一个通用编码器处理所有图片。

PNG 正式构建继续使用 OxiPNG 10.1.1 arm64；JPEG 继续使用 `mozjpeg-lossless-optimization`。

## 默认：智能无损

默认流程：

```text
读取真实 magic bytes
→ 判断 JPEG / PNG
→ 生成若干无损候选
→ 解码候选
→ 对 RGBA 像素做 SHA-256
→ 必须与原图完全一致
→ 只保留体积最小的候选
→ 重新封装 CBZ / ZIP / EPUB
```

### JPEG

- 不缩放；
- 不重采样；
- 不修改 JPEG 量化质量；
- 使用 MozJPEG 无损重排/Huffman 优化；
- 默认允许清理无关 metadata；
- 但如果存在 ICC profile、非正常 EXIF Orientation 或特殊色彩模式，会自动保留 JPEG markers；
- 优化后解码像素必须完全一致。

这修正了 v1.4“体积优先”可能过度清理 JPEG 显示相关 metadata 的风险。

### PNG

提供三种策略：

- **快速无损**：OxiPNG `-o 4`；
- **智能无损（默认）**：根据文件大小、图像熵、线稿倾向和像素规模决定是否继续尝试 `-o 6` / `-o max -z`；
- **极限无损**：固定比较 `-o 4`、`-o 6`、`-o max -z`。

每个 OxiPNG 候选都从同一原始 PNG 开始，避免“上一轮压缩结果继续喂给下一轮”导致比较失真。最终不假设更高优化等级一定更小，而是按实际字节数择小。

仍然不使用 OxiPNG `--alpha`。

## 真实格式识别

OCR、扫描、图像编辑工具偶尔会生成“扩展名和真实内容不一致”的文件，例如：

```text
page001.jpg  ← 实际内容是 PNG
```

v1.5 对 JPEG / PNG 使用 magic bytes 判断：

- 直接选择多张图片生成 CBZ 时，会按真实格式写入 `.jpg` / `.png`；
- 压缩包内部即使后缀不可信，也会按真实内容选择 JPEG 或 PNG 优化器；
- 结果摘要会记录发现的格式不一致数量。

已有 EPUB 内部文件不会擅自改名，因为 XHTML / OPF 可能引用原路径。

## 可选：扫描件预处理

这是单独的显式选项，默认关闭，并在 GUI 中用警告提示：

> 会改变图像像素或页面几何，不属于无损压缩。

可启用：

- 保守自动裁边；
- 最大 ±3° 轻微纠斜；
- 轻度 / 强力纸面与线稿增强；
- 彩色插图/高饱和区域保护。

### 保守裁边

只有在边缘与中心亮度差异足够明显、裁除比例落在保守区间、保留面积足够大时才裁切。全出血插图、已经裁好的漫画页、检测不确定的页面保持原几何。

### 纠斜

在缩小灰度图上测试 0.5° 间隔的小角度候选，使用水平/垂直墨迹投影的方差作为清晰度评分。只有最佳候选相对原图有明确收益才执行旋转。

### 纸面/线稿增强

- 大半径 Gaussian Blur 估计纸面背景；
- 背景扣除做亮度平坦化；
- 轻度 autocontrast；
- 轻度 UnsharpMask；
- 纸白、黑墨、强边缘、高饱和彩色区域从原图保护性合成回来。

不引入 AI 模型，也不引入 OpenCV/NumPy 运行依赖。

## 容器安全与稳定性

- ZIP 路径穿越检查；
- 拒绝超过 100,000 项的异常 ZIP；
- 拒绝理论展开总量超过 25 GiB 的 ZIP；
- 尽量保留 ZIP entry 时间、权限、注释和 archive comment；
- JPEG/PNG/GIF/WebP 等本身已压缩媒体在 ZIP 中使用 `STORE`；
- XHTML/XML/OPF 等文本使用 Deflate level 9；
- EPUB `mimetype` 永远第一项且 `ZIP_STORED`；
- 默认无损模式下，如果整个现有 CBZ/ZIP/EPUB 最终没有变小，则新输出直接保留原容器内容；
- 扫描件预处理是用户明确要求的图像变化，因此即使文件变大也不会偷偷回退为原图。

## 取消行为

OxiPNG 改为可取消子进程：GUI 点击取消后会先 terminate，超时再 kill，不再出现 Python 线程已取消但外部压缩器仍继续跑满 CPU 的情况。

## CI 合同

Apple Silicon CI 需要实际验证：

- OxiPNG 10.1.1 arm64；
- JPEG/PNG 智能无损；
- JPEG EXIF Orientation 保护；
- PNG 多候选择小；
- 所有无损输出逐像素一致；
- 假 `.jpg` / 真 PNG 的格式识别；
- CBZ archive comment 保留；
- EPUB `mimetype` 第一项且不压缩；
- 极限无损仍然逐像素一致；
- 扫描预处理作为独立的有损/几何变化路径测试；
- GUI 默认进入“智能无损”，扫描预处理默认关闭。
